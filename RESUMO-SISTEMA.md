# Sistema de Emissão de Laudos de Inspeção Técnica - Easy Laudos

## Resumo Executivo

O **Easy Laudos** é um sistema web desenvolvido em Next.js para emissão automatizada de laudos de inspeção técnica veicular. A plataforma gerencia clientes, veículos e equipamentos de medição, emitindo cinco tipos de laudos (Checklist, LIT, Ruído, Pino Rei e Quinta Roda) em PDF, com controle multi-usuário, upload de imagens, histórico completo e notificações de calibração, otimizando o fluxo de trabalho de empresas de inspeção veicular com conformidade às normas técnicas.

## Principais Tecnologias Utilizadas

- **Next.js 15.3.3** - Framework React com SSR/SSG
- **React 19.0.0** - Biblioteca de interface
- **TypeScript 5.x** - Tipagem estática
- **Prisma ORM 6.9.0** - Gerenciamento de banco de dados
- **SQLite** - Banco de dados relacional
- **pdf-lib** - Geração de PDFs
- **Puppeteer** - Renderização avançada de PDFs
- **Tesseract.js** - OCR para leitura de documentos
- **Docker** - Containerização
- **Nginx** - Proxy reverso
- **JWT** - Autenticação segura
